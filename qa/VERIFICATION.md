# v0.1.0 历史验证

2026-10-09。实机 Godot 4.7 RC 自定义引擎 / Forward+ Vulkan / NVIDIA RTX 5070 Laptop GPU。

## 验收

独立 Windows `build/AshenGears.exe` 和同目录 PCK 运行 `-- --qa --capture-dir=...`。33 项检查全部通过，报告 `runtime_tests.json`。测试组合使用真实 Godot Input 行走、跳跃、攀梯、折返、钩索和重击，以及直接状态注入检查存档、弹反、任务门和错误恢复。不是完整人工通关或实体手柄测试。

覆盖：起点接地、行走、跳跃落地、井盖解除碰撞、上下层梯子往返、两段折返深度切换、人类背后暗杀、机械／Boss 禁暗杀、救援守卫门、洛铆加入、空中切换保持位置速度、维修台获取钩索、遮挡锚点与高台通行、重击伤害、弹反与无敌帧、Boss／转运表旗标、P01 与简化 P02、技能学习、奖励和机关存档、11 个前进门落层与连接、能力门拦截、损坏存档备份恢复、地图暂停。

## 画面

`exe_screenshots/` 为导出 EXE 的 10 张截图，不是参考图片或 Blender 离线渲染。逐张检查标题、开盖、上梯、下楼、钩索高台、Boss、齿轮、地图、技能和维修所：UI 中文清楚，角色有平台支撑，楼梯深度可区分，锚点及暖灯可读。Boss 原型在近距攻击时遮住角色部分身体；高台仍为灰盒，参考图的精雕、场景密度和布料未达成。模块重复及远景分面需要后续精修。

## 资源与导出

`animation_manifest.json` 记录 14 个原通道动作和 8 个新增战斗动作；`asset_audit.json` 记录 GLB 网格、嵌入图像、动画及 SHA256。Blender 源文件在 `source/`，参考 demo 文件保持原状。源工程导入可有编辑器设置保存／退出资源提示；导出改用项目内 TEMP 后独立 EXE 能正常启动并完成验收。损坏存档用 JSON 实例错误码处理，回退备份。

没有做人工完整通关、实体 Xbox、不同显卡、最低配置、主观音频、性能压力或完整设计内容验收。不能把 33 项局部检查推导为完整版已完成或所有机器兼容。

发布包含 EXE、PCK、操作说明、Godot 许可证、第三方声明、运行验收报告和 SHA256 清单。打包脚本核对复制后文件和 ZIP 内文件内容哈希。
