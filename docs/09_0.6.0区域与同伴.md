# 0.6.0 · 区域推进、同伴收集与统一设置

本次以原有三个设计文档为世界观和区域命名参考，保留前 18 个房间索引与 0.4 系列存档结构，增加 R03—R06 共 32 个房间。当前是可玩的开发版本，覆盖前六个主线区域，尚未实现文档中的 R07—R12 与完整结局。

## 路线与回访

主线：灰闸囚厂 → 锈脊齿轮井 → 雾肺水务区 → 黑棘迁木园 → 夜血城堡 → 神笔实验室。余烬维修所与矿牢是支线，合计 50 个房间。

金色右门写出目的地；向右走自动推进，E 也可交互。左门向左走自动返回前室，并出现在前室右门内侧，避免传送后立刻再次触发。侧线矿牢返回轴承台侧门位置。旧版第二章终点改为水务入口，最后实验室运输梯才显示阶段完成，可主动回访。不存在用越界房号静默回到最后地图的处理。

每个休息灯保存、恢复全队与药剂，打开整备菜单；可选择已发现区域入口传送、同伴编队或任务记录。传送只通向已经到访的区域入口，不能绕过未发现的主线。普通敌人重新巡逻，奖励只领取一次；Boss 保留击败记录。

## 设置与性能

标题与 Esc 菜单的统一“设置”下有三类：

- **氛围与画面**：高中低、屏幕原生分辨率至 4K、显示模式、帧率上限、垂直同步、渲染比例、阴影、FPS、环境雾、辉光、环境亮度。显示修改需在 15 秒内确认，超时恢复。
- **音频**：总音量、战斗音效、音乐、环境分开调整，支持试听与恢复。57 个原创音频资源，包括四个新增区域的循环底噪，20 路动作音效并发。
- **按键**：22 项动作，分页改键，自动保存；重复占用与系统保留键被拒绝，Esc 取消录入。方向键、鼠标攻击与手柄默认布局保留。HUD 显示当前主要按键。

5070 默认高档；核显默认低档，1060 一类设备默认中档。各档保留全场景几何、动画与命中特效。改进方式为模型强引用缓存、贴图共享、静态部件分组合批、敌人感知与边缘查询间隔 0.12 秒、弹道网格与材质复用。物理及战斗有效帧保持 60 Hz。

普通入口使用 Forward+；老核显可用兼容启动脚本。性能报告为当前机器的 1080p 测量，不能代替 GTX 1060 或核显实机结果。资源和动作不做删除以换取帧率；低档可按需启用阴影。

## 构建与验证

Blender 源文件与 GLB 都保存在项目中；`source/build_v06.py` 可生成区域部件、四名同伴的八段骨骼攻击动画及四个首领模型。`source/rooms_v06.py` 重建完整房间数据。新增环境声音由 `source/build_audio_v06.py` 确定性合成，无外部录音。角色美术沿用原 demo 骨架，是开发期模型。

打包脚本必须通过导出的实际 EXE 验收并核对 EXE/PCK 哈希后才发布。验收报告为 `qa/runtime_tests.json`，新内容专项报告为 `qa/v06_runtime.json`，性能报告为 `qa/performance_v06_*.json`。原三份设计文档保留。
