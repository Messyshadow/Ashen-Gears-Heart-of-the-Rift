# 1.0.1 打击感优化

依据本地 `docs/action/astra-godot-action-skills/` 中 combat-feel、combat-animation、camera-feel、gameplay-vfx、enemy-ai、boss-ai、player-controller、playtest，以及 `02_玩法与开发设计.md` 第 6 / 13 节实施。保留原 Blender 模型、动画文件、地图、存档与职业招式，没有更换框架。

## 体验变化

- **命中动作同步**：由权威战斗时间按前摇 / 命中 / 收招采样既有骨骼动画。匕首等在动画中段的接触姿势结算，太刀前两刀使用 42% 接触姿势，第三刀 / 重劈取 52%；原匕首 / 拳锤重击取 78% 的下落挥击姿势，而不把举武器的峰值当接触，不再让短攻击只播放长动画的开头。
- **匕首三段层次**：总时长 / 前摇为 0.31 / 0.09、0.36 / 0.11、0.49 / 0.16 秒；各段独立，第三段采用中击反馈。匕首接触顿帧 35 / 40 / 55 ms，重击 70 ms；拳锤重击 90 ms，太刀重劈 110 ms。角色伤害、技能花费与武器范围保留。
- **连招节奏**：真实近战命中后，最后有效段及 80 ms 间隔结束即允许缓存轻击接续；挥空仍需 90% 收招。前摇不能反复翻滚取消，顿帧接收输入，受伤清理旧输入。远程发射保持原取消边界。
- **实体受击**：轻 / 中 / 重 / 终结击退速度 3 / 4.5 / 6.5 / 7 m/s，减速 18 m/s²。移动通过原物理碰撞，不直接传送。群体近战对左右目标分别向外击退；首领仍按破势门槛保持霸体或受击，未改为轻击无限硬直。
- **可读的刀光与接触圈**：有效帧才产生短刀光；击中时在目标实际接触点显示冲击圈与定向粒子。血肉红色、机械金属暖色、亡灵紫色、弹反蓝色、盾牌阻挡金色。远程使用实际扫掠点，移除重复通用命中火花，挥空不发重命中声。
- **声音重量**：保留原材质命中声，重击 / 终结叠加原创 0.20 秒低频冲击声，增益 -8 dB。同一物理帧只叠一层低频，避免群体命中过响。音频资源共 64 个。
- **击杀收尾**：先提交原唯一奖励与击败状态，再保留约 0.30 秒模型倒下与缩小收尾；关闭碰撞、隐藏标签，之后释放节点。尸体不能重复结算命中、共鸣、吸血或掉落。
- **舒适度**：设置 → 氛围与画面 → 战斗反馈，分别提供镜头震动、闪光、缩放、血雾、手柄震动 0 / 25 / 50 / 100%。关闭震屏或血雾仍保留接触位置、声音和实际伤害。配置写入已有画面设置文件，旧配置自动补默认。

## 参数与所有权

`scripts/action_tuning.gd` 集中保存时序、接触姿势、击退、顿帧、命中取消和效果池上限。`player_v04.gd` 负责权威攻击时间与采样，`enemy_v04.gd` 负责实体受击 / 击杀，`action_feedback.gd` 统一局部顿帧、闪白、镜头、粒子、冲击圈与音频层。没有调整全局时间缩放。

镜头衰减与新增短方向脉冲叠加于原跟随相机；按与玩家的距离衰减，16 米外不震屏。同一物理帧和 80 ms 窗口按最大强度处理，保留原幅度与缩放上限。冲击圈 / 刀光同时最多 12 个，共享几何、逐节点复用材质，换房释放；既有火花池保留。

## 优化前后实机探针

同一隔离房间、相同人物、同一敌人及重击，原始记录分别为 `qa/impact_before_v101.json` 与 `qa/impact_after_v101.json`。

| 观察 | 1.0.0 | 1.0.1 |
| --- | --- | --- |
| 首次伤害时动画进度 | 20.8% | 52.3% |
| 重击后 0.55 秒敌人净水平位移 | 0.064 m | 0.907 m |
| 击杀后紧邻渲染帧仍能看到模型收尾 | 否 | 是 |

这是实际运行采样，不是策划的手感评分。普通敌人硬直结束后仍会恢复 AI，所以净位移不是公式最大位移。旧顿帧专项用重击验证完整观察窗口；新增专项单独验证更短的匕首命中同步和快速连招，避免用过长采样窗口判定短顿帧不存在。

专项包含原动作 26 项及新增 22 项，实机编辑器场景 48 项零失败、错误日志为空：动作同步、接触点、实际刀光、命中与挥空取消、实体击退、群攻最大值、远处镜头衰减、强度关闭与持久化、五项 UI、护甲 / 亡灵差异、首领霸体、池上限与复用、尸体防重复、收尾释放及换房清理。最终发布 EXE 332 项回归零失败、错误日志为空，同包 OpenGL 低档 13 房检查通过。记录与 SHA256 以 `qa/runtime_tests.json` 为准。

没有声称完成实体手柄触感或低配硬件试玩；手柄震动已接入可用设备 API，但当前无实际手柄检验。该轮为可执行改进，主观重量感、视听舒适度与密集战斗性能需策划继续检验。

## 建议试玩顺序

同一敌人依次使用匕首、太刀、拳锤，比较轻击三段、重击及挥空；连续输入轻击，在命中与挥空两种情况下接翻滚；平台边、斜坡上测击退；两三个敌人同时受击时观察读招是否被挡；面对盾卫和亡灵比较声画；首领轻击、破势、弹反与击杀；最后把五项反馈调为 0 / 50 / 100%，检查设置保存和镜头舒适度。
