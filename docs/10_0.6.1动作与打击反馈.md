# 0.6.1 · 动作输入与打击反馈

参考 `action/astra-godot-action-skills/` 中的 player-controller、combat-feel、combat-animation、camera-feel、gameplay-vfx、enemy-ai、boss-ai 与 playtest 流程。参考规范中的数值用于确定方向，实际参数按当前七名角色、匕首与太刀的节奏选择。保持现有 Godot/GDScript 结构、Blender 模型、50 房间、存档和设置。

## 修复的问题

0.6.0 的命中顿帧依赖全局标记：攻击逻辑暂停时，所有敌人和弹道也会暂停，但骨骼动画仍继续。修改前的实际探针结果保存在 `qa/action_baseline_v061.json`：命中后的采样区间中，旁观敌人的逻辑推进为 0，攻击动画推进约 33 毫秒。

新实现只暂停近战攻击者与受击者的本地物理/战斗时钟，并同时暂停 AnimationPlayer；旁观敌人、弹道、机关、背景、音乐、粒子继续推进。没有修改 `Engine.time_scale`。玩家远程弹道命中只暂停目标，不冻结已经在自由移动的射手。动画与状态使用物理时间，受击动画零过渡切入；首领半血阶段标记独立更新，不被顿帧推迟。

旧轻击输入会无限留存到收招，且主要支持匕首/太刀。现在输入有有效期：攻击 220 毫秒、翻滚 120 毫秒。轻击在有效帧结束且经过 72% 的总时长后可以衔接下一次轻击，80% 后允许翻滚取消；重击和技能须完成收招。多段技能的取消边界在最后有效帧之后。顿帧期间仍接收输入，攻击中换人/换武器的约束保留。过早输入会自然过期，受伤、菜单与倒地接替会清掉旧输入，避免幽灵出刀。

环境受伤与战斗受伤都清理攻击、多段命中、飞刃、钩索、翻越、翻滚与冲刺状态，恢复后不会自动续冲或补发旧招式。二段跳使用状态继续保留，不借取消刷新身法次数。

## 集中调参

`scripts/action_tuning.gd` 集中保存移动、缓冲、攻击时序、有效窗口、反馈和镜头参数。原招式前摇/总时长、伤害、距离及耐力花费保持原有值；此版本改变输入衔接与反馈，不提升角色伤害。

| 项目 | 当前值 |
| --- | --- |
| 土狼时间 / 跳跃缓冲 | 100 / 120 毫秒 |
| 初始跳跃 / 二段跳速度 | 12.5 / 11.8 米/秒 |
| 地面 / 空中加速度 | 30 / 15 米/秒² |
| 轻击 / 中击 / 重击 / 处决顿帧 | 50 / 75 / 110 / 120 毫秒 |
| 弹反 / 格挡顿帧 | 80 / 25 毫秒 |
| 连续命中顿帧衰减 | 500 毫秒内重复命中，每次减少 20%，下限为原时长 55%；时长取最大值，不累加 |
| 震屏 Trauma 上限 | 0.8，平方衰减；与基础跟随分离 |
| 镜头推进 | 正交尺寸最多降低约 1.2%；总览不加入震屏 |
| 火花数量 | 轻 7、中 11、重 15、处决 18；各画质一致 |

`action_feedback.gd` 统一触发局部顿帧、闪白、模型微抖、分级镜头、定向火花和同步音效。闪白采用短时 additive 覆盖，不替换原 PBR 材质/贴图；微抖只改变模型局部位置，不移动碰撞体。原音频事件与混音总线继续复用。火花共享网格/材质、结束后进入最多 96 个实例的复用池，换房清理。闪白材质在角色进入场景时以极低强度短暂预热，减轻首次命中才创建渲染管线的问题；不声称消除所有驱动编译卡顿。

普通敌人的受击硬直和击退分级；首领保留霸体，达到破势门槛或弹反才打断，不把每次轻击变为首领硬直。现有 AI 招式选择和关卡配置保持。

## 验证与实际限制

`source/playtest_actions.gd` 可以独立运行动作场景；`scripts/qa_actions.gd` 也接入完整 Windows EXE 验收。场景包括双方动画/逻辑冻结、旁观者和弹道推进、闪白撤销、定向粒子及复用、重轻反馈差异、重复命中衰减、震屏上限、过期输入、顿帧连招、翻滚取消、受伤中断、短/长跳、提前落地按跳、真实台边土狼时间、霸体/破势、弹反与换房清理。实际结果见 `qa/actions_runtime_v061.json`、`qa/runtime_tests.json` 和 `qa/VERIFICATION.md`，截图位于 `qa/action_screenshots/`。

自动场景使用真实 Godot 输入动作、固定物理和渲染，不能替代人工判断重量感，也没有实体手柄或核显/1060 实机验收。下一轮人工试玩建议：同一敌人分别用匕首、太刀、重锤、双刃作战；在斜坡和平台边快速转向、短跳、二段跳、连招接翻滚；在两名敌人夹击及 Boss 半血阶段连续弹反，确认读招和镜头舒适度。
