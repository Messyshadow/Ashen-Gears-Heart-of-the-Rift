# Astra / Codex Godot Action Skills

Eight project-focused Codex skills for a Godot 2D/2.5D action/metroidvania workflow.

Included:

1. combat-feel
2. combat-animation
3. player-controller
4. enemy-ai
5. boss-ai
6. gameplay-vfx
7. camera-feel
8. playtest

## Recommended installation

### Project-scoped (recommended)
Copy the eight skill folders into your game's `.codex/skills/` directory so the rules travel with the project:

`<your-game>/.codex/skills/<skill-name>/SKILL.md`

### User-wide
If you deliberately want the same skills available to every Codex project, copy them to your user Codex skills directory, typically:

`C:\Users\<you>\.codex\skills\`

Project-scoped installation is safer because these skills are specifically written for this action-game workflow. Restart/reload Codex after installing if the current session does not discover them immediately.
