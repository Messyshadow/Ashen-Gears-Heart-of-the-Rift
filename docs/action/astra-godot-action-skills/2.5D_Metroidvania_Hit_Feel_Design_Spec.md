# 2.5D 银河恶魔城打击感（Hit Feel / Impact Feedback）设计规范

> **用途**：直接提供给 Codex / GPT-6-Astra 使用的完整设计文档  
> **参考游戏**：《暗影火炬城》《死亡细胞》《空洞骑士》《银河战士》系列 + 格斗游戏（街霸、罪恶装备）成熟实践  
> **核心目标**：解决打击感偏软、缺乏重量与反馈层次的问题

---

## 一、核心原则（必须先理解）

**一次真正爽的打击 = 5～8 个反馈层在 80～150ms 内同时触发。**

缺少任何一层都会变“软”。成熟动作游戏从不只靠动画或特效，而是**分层叠加 + 按伤害/攻击类型分级强度**。

参考研究（arXiv:2208.06155）和实际游戏：影响玩家“冲击感”最大的三个要素是：

1. **Hit-Stop（卡帧 / 冻结帧）**
2. **音效同步与连贯性**
3. **镜头控制（震屏 + 轻微推拉）**

其他层（粒子、闪白、击退、受击抖动、数字弹出）是增强项。

---

## 二、打击感完整反馈栈（按时间顺序实现）

每次成功命中时，必须按下面顺序触发（所有层可配置强度）：

| 顺序 | 反馈层 | 推荐参数（普通攻击） | 重击 / 暴击 | 备注 |
|------|--------|---------------------|-------------|------|
| 1 | **Hit-Stop（卡帧）** | 40～80ms，timeScale 0.05～0.15 | 100～160ms | 最核心。攻击者+受击者同时冻结 |
| 2 | **受击闪白 / 闪色** | 白色或攻击属性色，1～2帧 | 更强、更长 | 材质/Shader 闪一下 |
| 3 | **受击抖动（Hit Shake）** | 模型局部 ±2～5px 快速抖动 | 更强 | 只抖视觉模型，碰撞盒不动 |
| 4 | **击退（Knockback）** | 小向量 + 短时间 | 更大向量 + 可能浮空 | 在 Hit-Stop 结束后立即生效 |
| 5 | **屏幕震动（Screen Shake）** | Trauma 0.15～0.4 | Trauma 0.6～1.0 | 用衰减 Trauma² 方式，不要随机抖动 |
| 6 | **粒子 / 火花 / 血迹** | 6～15 个粒子 | 20～40 个 + 特殊特效 | 方向跟攻击方向一致 |
| 7 | **音效** | 短促“铿/啪”音 + 低频冲击 | 更厚重 + 多一层 | 必须和 Hit-Stop 同步（误差 <15ms） |
| 8 | **伤害数字 / 飘字** | 可选，带轻微缩放弹出 | 更大、带暴击标识 | 用 easeOutBack 缓动 |

### 关键时间线示例（普通命中）

- **0ms**：碰撞判定成功 → 立即触发 Hit-Stop + 闪白 + 音效
- **0～60ms**：双方冻结（攻击者停在武器深入的帧，受击者停在受击动画第一帧并抖动）
- **60ms 后**：恢复时间 → 击退开始 → 粒子飞出 → 震屏衰减

## 三、Hit-Stop（卡帧）详细实现规范

这是 AI 最容易做错的地方。请严格按下面做。

### 推荐实现方式（优先级从高到低）

#### 1. 局部动画冻结（最佳，尤其 2.5D）

只冻结攻击者和受击者的 Animator / Animation 播放速度，或暂停他们的本地时间。  
其他世界物体、背景、粒子继续跑。  
这样不会让玩家觉得“游戏卡了”。

#### 2. 全局 TimeScale 降低（简单但要小心）

**Unity 示例（必须用 Realtime）**：

```csharp
IEnumerator HitStop(float duration = 0.06f, float scale = 0.08f) {
    Time.timeScale = scale;
    yield return new WaitForSecondsRealtime(duration); // 关键！不能用 WaitForSeconds
    Time.timeScale = 1f;
}
```

**Godot 对应**：

```gdscript
func hit_stop(duration := 0.08, scale := 0.05) -> void:
    Engine.time_scale = scale
    # 第4个参数 ignore_time_scale=true → 计时器在冻结期间仍会触发
    await get_tree().create_timer(duration, true, false, true).timeout
    Engine.time_scale = 1.0
```

#### 3. 帧数计数冻结

在 FixedUpdate / 自定义更新里跳过指定帧数的逻辑更新，但继续渲染。

### 必须遵守的规则

- **攻击者和受击者同时冻结相同时间**（格斗游戏黄金法则）。
- Hit-Stop 长度与伤害正相关：轻击 3～5 帧（50～80ms），重击 8～12 帧，终结技更长。
- **Hit-Stop 延迟（Hit-Stop Delay）**：有些攻击命中判定帧比“视觉上武器最深入”的帧早。可给 Hit-Stop 加 1～3 帧延迟，让冻结发生在“剑深深插进身体”的视觉最佳帧。
- 受击动画切换时 **Transition Duration = 0**（否则会感觉力被缓冲掉）。
- 连续命中时做**硬直衰减**：第二次开始 Hit-Stop 缩短 20～30%，防止连击变卡。
- 区分 **Hit-Stop（纯手感冻结）** 和 **Hit-Stun（真正的受击硬直状态）**。两者可以独立。

### 2.5D 特殊注意

- 因为角色是 3D 模型，Hit-Stop 期间最好给模型加轻微的“受击抖动”（本地坐标 X/Y 快速微抖），碰撞盒保持不动。这和《暗影火炬城》的铁拳手感非常接近。
- 镜头最好轻微朝命中点推近一点（Camera Zoom / FOV 变化），再快速回弹。

## 四、按参考游戏拆解风格

### 1. 《暗影火炬城》（最推荐作为 2.5D 主参考）

- 打击非常“实”和“重”。
- **铁拳**：短而有力的 Hit-Stop + 明显击退 + 金属火花 + 厚重音效。
- **钻头**：更长的持续接触感，Hit-Stop 可以做成短时间慢动作。
- **电鞭**：相对轻快，Hit-Stop 更短，强调速度感。
- 整体特点：**武器切换无缝 + 连招自由，但每一下都很有重量**。

### 2. 《死亡细胞》

- 极致的“Juice”。
- 重武器：明显 Hit-Stop + 强震屏 + 大量粒子。
- 暴击 / 特殊命中：1 帧完全冻结 + 短慢动作。
- 参考开发者原话：大量借鉴格斗游戏（街霸、BlazBlue）的卡帧、粒子、慢动作。

### 3. 《空洞骑士》

- 精准、克制、响应快。
- Hit-Stop 较短但非常干净。
- 受击时全屏粒子冲击感强（玩家受伤时更明显）。
- 适合作为“轻量精准”风格的对标。

### 4. 《银河战士》系列

- 更强调能量武器的冲击与环境反馈。
- 导弹 / 超级导弹有明显的冻结 + 震屏 + 爆炸粒子。
- 适合远程 / 特殊武器参考。

## 五、分级反馈系统（必须做）

不要所有攻击用同一套参数。建议做一个简单的 **Feedback Tier**：

```csharp
enum HitTier {
    Light,    // 普通轻击
    Medium,   // 重击 / 蓄力
    Heavy,    // 终结技 / 处决
    Critical  // 暴击 / 弱点
}
```

每个 Tier 对应不同的：

- Hit-Stop 时长与 scale
- 震屏 Trauma 强度
- 粒子数量与尺寸
- 音效音量与低频
- 击退力度
- 是否触发镜头轻微 zoom

调用时只传一个接口：

```text
PlayHitFeedback(HitTier tier, Vector3 hitPoint, Vector3 direction)
```

## 七、给 GPT-6-Astra / Codex 的最终指令模板

可直接复制以下内容作为 Prompt：

```text
请严格按照以下规范实现 2.5D 银河恶魔城的打击感系统：

1. 每次命中必须同时触发：Hit-Stop + 受击闪白 + 受击模型抖动 + 击退 + Trauma式震屏 + 粒子 + 同步音效。
2. Hit-Stop 优先使用“只冻结攻击者与受击者动画/本地时间”的方式，避免全局卡顿感。如果用 Time.timeScale，必须配合 WaitForSecondsRealtime。
3. Hit-Stop 时长与攻击强度正相关，普通攻击 50-80ms，重击 100-150ms。支持 Hit-Stop Delay。
4. 受击动画 Transition Duration 必须为 0。
5. 连续命中做硬直衰减。
6. 反馈强度按 Light / Medium / Heavy / Critical 四级配置。

8. 镜头使用衰减 Trauma 震屏（shake = trauma²），不要用简单随机偏移。
9. 所有反馈必须在命中判定成功的同一帧内启动，音效与视觉误差 < 15ms。

实现时请先写出可配置的 FeedbackManager / HitFeedback 系统，再接入具体攻击。
```

## 八、快速检查清单（验收用）

实现完成后，用以下标准自检：

- [ ] 普通攻击有明显短卡帧，重击卡帧更长
- [ ] 攻击者与受击者同时冻结
- [ ] 受击动画无过渡时间（硬切）
- [ ] 命中瞬间有闪白 + 模型微抖
- [ ] 震屏使用 Trauma 衰减而非随机抖动
- [ ] 音效与卡帧严格同步
- [ ] 不同攻击强度反馈有明显差异
- [ ] 连击不会因为卡帧过长而卡顿
- [ ] 粒子方向与攻击方向一致
- [ ] 2.5D 模型在卡帧期间有局部抖动，碰撞盒稳定
