# 0.4.2 性能、画面设置与章节终点

2026-10-10。优先减少重复工作，保留环境氛围、模型和战斗动作。正常 Windows 入口使用 Forward+，三个画质档位可随时切换。物理仍固定 60 Hz。

## 不降低内容质量的优化

1. 相同静态模型按 8 米空间格合批为 MultiMesh；平台的碰撞体、斜梯、动态吊台、压锤、旋转齿轮和交互道具保持独立。空间格保留视锥剔除能力。批量网格和材质跨房复用。
2. 相同材质共享 ShaderMaterial；工业模型资源保持引用，减少反复载入和创建。角色骨架、所有动画、命中顿帧和物理照常更新。
3. 七个 GLB 内重复的嵌入贴图改为 22 个外部共享原图：61.79 MB 重复嵌入图片变为 24.05 MB 唯一图片。原图字节不变；几何、骨架、动画、材质参数和所有非图片缓冲数据逐项比对通过。模型与共享图片合计由 74.10 MB 变为 36.35 MB。源 .blend 保留；重建流程自动再做去重。
4. 完整保留贴图尺寸、法线、粗糙度和各向异性过滤，开启 mipmap。特效复用球体网格和材质，每次命中仍创建七粒相同效果。HUD 以 30 Hz 更新，游戏模拟与动画不降频。正常退出先停止循环音频，再关闭游戏，释放播放资源。

未删房间、装饰、远景、动作、声音或特效数量。原有模型与文档保留在仓库；发布包还带历史资源，所以包体大小不等于本次活跃资源去重后的大小。

所有档位保留雾、冷暖光色、灯具自发光、熔浆动态着色、场景几何与完整战斗效果。5070 等 RTX 30/40/50 自动推荐高档；GTX 推荐中档、常见 Intel 核显推荐低档，用户设置优先。推荐只按设备名称选择，不代表该硬件已通过帧率验收。

## 显示与帧率

标题 / Esc → 画面设置。默认全屏、当前显示器原生分辨率、60 FPS 上限和垂直同步。提供 1280×720、1600×900、1920×1080、2560×1440、3840×2160，帧率上限 30/60/90/120/144/165/240/不限，50/67/85/100% 渲染比例及动态阴影、FPS 显示。

全屏不修改 Windows 显示模式，而是保持屏幕尺寸，按所选分辨率与渲染比例调整 3D 缓冲；UI 单独保持清晰。窗口模式改变窗口大小，超出工作区则适配。16:9 界面使用等比布局，其他宽高比保留边条。

点击应用后 15 秒确认。确认保存到 `user://graphics_settings.cfg`；超时、Esc 或选择恢复回到之前设置。画面更改不写入角色存档。F11 在全屏/窗口之间切换。开启垂直同步时，实际帧率仍受显示器刷新率和硬件性能限制；帧率上限不保证达标。

老旧驱动或核显可使用 `AshenGears-LowSpec.cmd`，强制 OpenGL 兼容渲染与低档；角色进度共用。兼容入口不支持 SSAO/辉光和 FXAA，高质量光影使用普通入口。它不是保证更快的入口，各驱动性能需实测。

## 性能实测

RTX 5070 Laptop GPU，1920×1080，关闭垂直同步、不限制帧率；每房热身 1.5 秒、采样 240 帧，相同移动输入。以下比较 0.4.1 与 0.4.2 **高档**，保留完整光影。数字为这台设备的样本，不是 1060 / 核显实测。

| 房间 | 平均绘制调用 | 减少 | 平均帧时间 |
| --- | --- | --- | --- |
| 三层压料台 | 471 → 265 | 43.8% | 2.54 → 2.47 ms |
| 四层配速井 | 444 → 268 | 39.6% | 2.56 → 2.50 ms |
| 督工轴心 | 319 → 200 | 37.1% | 2.53 → 2.52 ms |

5070 高档平均帧时间仅有小幅变化，不能把绘制调用下降直接当成相同比例的帧率提升。中低档主要减少像素、阴影与灯光开销。所有档位的逐房帧时间、95 分位、绘制调用和纹理/显存监测在 `qa/performance_*.json`；显存监测包含渲染附件，不等于驱动全部分配。房间构建时间不包含全部首次加载和驱动编译。

`qa/asset_validation.json` 独立比对原模型和去重模型，确认几何、动画和原图无变化。实际 GTX 1060 / 核显尚未测试。复测建议先用原生屏幕、中档、60 FPS；核显再选低档、720p 或 67% 渲染比例，打开帧率显示，并在压料台、四层井与 Boss 房检查。

开发性能复测（使用独立 benchmark 存档）：

## 第二章终点

原维修桥出口自动载入维修所，把结束对白覆盖了；维修所出口也指回维修桥，容易误以为新主线在循环。现在维修桥右侧出口停在「R01 / R02 · 章节完成」，提供维修所整备、锈井回访、灰闸回访和返回标题。维修所右门改为明确的锈井入口回访。完成标志和奖励只记一次，旧存档进度兼容。

本次仍是两片区域共 18 房间，第三章雾肺水务区未开放；界面明确说明。没有把回访当成新增章节。

## 验收

原 81 项玩法、碰撞、身法、存档和实际音频混音检查，加 15 项画面/路由检查，共 96 项。检查原生默认值、高中低实际渲染状态、合批、完整粒子与远景、显示确认/超时恢复、设置持久化、菜单和章节终点。独立 EXE 报告在 `qa/runtime_tests.json`。兼容入口另有三个房间的 OpenGL 源工程性能检查，以及导出 EXE 普通启动和 240 帧绘制检查，未做完整人工通关、物理核显或实体手柄验收。
