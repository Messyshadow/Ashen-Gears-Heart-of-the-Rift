# 0.4.0 实现与验收

2026-10-10。以用户提出的“场景重复、没有敌人、通道相同、身法单一”为本次开发重点。01—03 原设计文档保持原状；04 保留作为 0.1 历史记录。

## 场景与连接

共享 Blender 工业部件替代五套整房模板的重复使用。18 间房逐一指定平台、斜梯、梯子、机关、敌人、目标、前后门。R01-01→08→R02-01→08→维修所为主线；R02-H1 从轴承台进入并返回轴承台。R01-06 捷径回巡逻暗道，出货门可回煤仓或维修所，备料场可回四层井，维修桥可回锈井入口。

前进门显示目标名称，右行跨过门的距离阈值即可切换；返回与回环需要 E，避免误触。入口接地、出口楼层、18 个前门连接逐项验收。换房自动更新重试位置；坠落扣血并重试当前房间，队伍全倒也在当前房间复活。休息灯保存实际站位，继续游戏恢复站位。

## 战斗、身法与角色

巡逻守卫、弩手、机械犬、炮台、飞行机械、典刑机、牛头督工采用独立行为与表现。普通敌人休息/重访刷新，铁屑只在首次击败时发放；Boss 保存永久击败旗标，不重生。远程弹道使用逐帧射线阻挡检测；炮台/飞行机械会朝角色高度射击。近战检查距离、方向和实体阻挡；伤害在有效帧发生，伴随短暂停顿。

冲跑、蹲行碰撞高度、跳跃缓冲/离地宽限、翻滚有效无敌帧、低障碍翻越、空中下砸、限时抓壁、蹬墙、连续钩索、每次腾空一次的空中冲刺进入控制器。原通道与战斗骨架保留，新增 Run、Crouch、Roll、AirDash、WallHold、WallKick、Vault、Slam、HookPull、MechLight、MechHeavy、BowShot 十二动作。

洛铆通过囚门救援加入；伊瑟通过可选矿牢救援加入。三槽切换保留原碰撞体、位置、速度、通道状态和腾空限制，独立 HP。角色有不同装备与动作，但仍是 demo 机器人骨架的测试美术。T 界面提供九节点、角色选择与隔离 SubViewport 动作预览，不改变游戏世界中的碰撞或攻击状态。

典刑机半血启用冲击波，牛头半血增加冲锋频率。Boss 仍为机制原型，尚无正式骨骼精修、完整处决与剧情演出。武器强化三档、药剂、宝箱、休息灯与地图沿用并接入新房间。

## 验证方法与范围

脚本 `scripts/qa_v04.gd` 在真实运行的 Godot 物理世界中驱动行走、跳跃、竖梯、整段斜梯、连续钩索、升降、翻越、空冲、下砸、抓壁与三段壁顶路线。局部战斗测试设置初始位置/状态，随后用真实攻击有效帧、弹道和碰撞验证；存档、唯一奖励和 Boss 阶段采用局部状态注入。所有前门也有短距离真实步行触发验证。没有把这组局部检查当作完整人工主线通关。

Windows EXE 再运行相同验收并输出实际截图，报告在 `qa/runtime_tests.json`。发布脚本核对复制文件及 ZIP 内容哈希。角色正式美术、精细烟雾布料、最低配置、其他显卡/实体手柄、R03 水务及后续区域不在本次完成范围。
