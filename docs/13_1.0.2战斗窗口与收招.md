# 1.0.2 战斗有效帧与收招优化

按照本地 `docs/action/astra-godot-action-skills/combat-feel/SKILL.md` 与 `playtest/SKILL.md` 继续优化：先复现漏判，再调整战斗时间与中断规则，最后运行专项和实际发布 EXE 回归。模型、骨骼动画、地图、技能树、背包、音效资源和三档画面配置沿用 1.0.1。

## 玩家可感知的变化

- **挥击整个有效窗口可命中**：此前只有前摇结束的那一帧检测。现在匕首、太刀、拳锤和其他近战职业在有效窗口内逐物理帧检查，敌人稍晚进入范围也能命中。每一段记录已经命中的目标，同一目标持续重叠只受伤一次；不同敌人各自结算。原距离、朝向、遮挡与伤害倍率保留。
- **多段技能保持独立结算**：每一段开启独立命中记录，三段技能对同一目标正好造成三次伤害。挥击特效仅在每段开始时触发，伤害、奖励、吸血、共鸣和命中声音也只在真实命中时结算。远程射箭和法术仍按原时间发射一次，不逐帧发射。
- **连招按真正接触时间推进**：缓存轻击需等到本段有效窗口结束、最后一次真实命中后至少 80 ms。挥空维持原收招边界。受伤、翻滚和死亡立即关闭旧窗口，避免恢复控制后补发上一刀的伤害。
- **普通重击后段可翻滚**：原本必须等全部收招结束；现在有效帧结束且攻击进度达到 85% 后，可消费正常耐力通过翻滚脱离。前摇不能取消，多段技能与高阶终式不套用此规则。
- **下砸落地有短收招**：接地只结算一次冲击，保留落地尘雾和声音，并增加 0.24 秒收招。收招期间不能切武器或人物跳过硬直，受伤可正常中断，结束后恢复输入。
- **耐力耗尽崩防**：格挡被击破或持续持盾耗尽耐力时，进入 0.60 秒崩防，清除旧连招缓存并恢复耐力。普通格挡减伤与完美弹反窗口保留。
- **尸体不干扰战斗**：自动瞄准跳过近处尸体，范围控制不把尸体改成眩晕状态；弹反来自已死亡敌人的弹道也不会打断其击杀收尾。
- **血雾设置与防御提示分开**：关闭血雾仍保留蓝色弹反、护甲格挡火花、声音与真实伤害。

## 参数与实现范围

`scripts/action_tuning.gd` 的 `ACTIVE_SECONDS` 保留原各招式时长：匕首 65 ms，太刀前两段 75 ms、第三段 85 ms、重劈 100 ms，其他近战按职业设置或 80 ms 默认值。新增 `RECOVERY` 集中保存普通重击取消比例 0.85、下砸 0.24 s、崩防 0.60 s 与崩防后退速度 3 m/s。

`player_v04.gd` 持有当前命中窗口、目标 ID 集合及实际接触时间；`game.gd` 使用已有距离与墙体射线完成检测，记录通过遮挡检测后的目标。窗口结束及时清空集合；已命中的目标先跳过，避免重复射线与反馈。沿用 1.0.1 的局部顿帧和效果池，不增加全局时间缩放、模型细节削减或新的实时光源。有效窗口额外覆盖数个物理帧，尚未在目标低配硬件上实测其性能影响。

同一隔离房间中，角色先向范围外敌人挥匕首，敌人在前摇结束后、有效窗口结束前进入范围。真实 Godot GPU 运行探针结果：

| --- | --- | --- |
| 本次挥击造成伤害 | 0 | 22 |
| 进入时仍处于有效窗口 | 是 | 是 |

原始证据 `qa/window_before_v102.json` / `qa/window_after_v102.json`；`source/window_probe.gd` 可复现。默认输出优化后记录，指定 `--report=` 可选择输出文件。

专项真实 GPU 场景 **73 项通过，0 失败**，包含已有 26 项动作、22 项反馈与新增 25 项有效帧 / 收招 / 崩防 / 尸体处理检查，错误日志为空。新增检查覆盖迟入目标、持续重叠不重复伤害、窗口后不补伤、多目标 / 三段技能、前摇与技能取消限制、实际输入重击翻滚、下砸恢复、崩防恢复、防御提示、尸体锁定及墙体遮挡。

最终发布 Windows EXE **357 项回归全部通过，0 失败**，错误日志为空；同包 OpenGL 低档 **13 个代表房间**通过，错误日志为空。结果与文件哈希见 `qa/runtime_tests.json`、`qa/compatibility_v10.json` 和 `qa/VERIFICATION.md`。发布脚本检查版本、零失败、空错误日志及 EXE / PCK SHA256，并校验发布目录与 ZIP 内容。

数据重建工具已运行，rooms / skills / quests / campaign / content 五个文件重建前后 SHA256 一致。此次没有重新生成 Blender 资产或音频资源。历史三档性能数据仍是 1.0.0 的 RTX 5070 Laptop 移动场景，不作为本次密集战斗、GTX 1060 或核显帧率结论。

## 策划下一轮试玩

1. 匕首与太刀在敌人走近时挥击，比较迟入目标命中、挥空与三段连招是否自然。
2. 普通重击末尾接翻滚，确认不能取消前摇；多段技能末段、终式不能提前跳过。
3. 平台、斜坡下砸后接轻击 / 翻滚，检查 0.24 秒收招的重量感与响应。
4. 低耐力连续持盾，检查崩防提示、恢复速度、完美弹反；关闭血雾后重复比较。
5. 击杀近处敌人后立刻射向后方敌人，确认锁定、尸体收尾与声音无异常。
