# 首版实现与开发路线

2026-10-09 / v0.1.0。原有三份设计文档不改写；本文件记录代码实际覆盖和后续缺口。

## 本次交付

首个 Godot 工程，从煤仓醒室到囚厂典刑机，再到锈井回流检修站及维修所。共 12 个房间使用五种既有 Blender 通道模板拼接，新增独立 Blender 机械资产和战斗动作。房间出口通过近距离 E 交互，前进门检查永久任务旗标；原路返回、Boss 前捷径、Boss 后煤仓回环及维修所连接已开放。

角色 P00 和 C01 均为 demo 机器人骨架的测试表现，不是人物正式美术。切人只改变当前 HP 归属、角色比例与伤害配置，保留同一碰撞体与运动状态。双方各两招；C01 的第一招在击打时恢复自身 12 HP，尚非设计中的护盾。魔力共享，切换冷却 1 秒；切换不产生无敌。梯子持续攀爬允许切换，进出和折返阶段禁止。

## 下一阶段顺序

1. 制作三层梯井和四层折返井，统一中层出梯与多梯管理；添加 A02 实体墙抓。
2. 独立角色模型、机械臂武器、攻击遮挡与可预览招式，完成 C02 招募和三人编队。
3. 把 P01 升降台、P02 浮筒接上可见运动，加入 B01 第二阶段和处决。
4. 精修 R01 各房差异、环境线索、音频与性能；再测完整 30—45 分钟样片体验。
5. 按原始设计分批推进 R03—R06、R07—R09、R10—R12。未实现内容不显示为可使用功能。

## 资源来源与 Git

用户指定的 `E:\SourceCode\Games\game\上下通道demo` 为基础资源来源；复制的是用户本地 `.blend`、嵌入纹理的 GLB 与通道控制／脚部修正／深度材质脚本。保留 demo 原文件。新增资产由 `source/build_ashen.py` 在 Blender 后台生成，不使用参考图片做场景替代。Git 管理工程、设计文档、模型与可编辑源文件；发布包和导入缓存不提交，原有 `.git` 保留。
