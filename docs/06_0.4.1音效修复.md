# 0.4.1 音效修复

2026-10-10。0.4.0 的短促合成音共用一个播放器，连续脚步/命中会相互打断；跳跃、突进、攀梯、钩索等动作缺少音效事件，背景低频也过轻。本次保留场景和 0.4 存档格式，替换音频系统并补齐事件。

## 声音与混音

`source/build_audio.py` 原创合成 53 个音频资产：材质脚步变体、攀梯、起跳与轻/重落地、翻滚、空冲、翻越、壁跳、钩索发射/锁定、轻重挥击、肉体/装甲命中、弓弦、格挡/弹反、技能、受伤、敌人前摇/发射、Boss 咆哮/冲锋/落锤/冲击波、吊台起停、齿轮、压锤预警/撞击、宝箱/休息/切人/过门/UI，以及四种环境底噪与三种配乐。

WAV 为 48 kHz 双声道 16-bit PCM。环境与音乐转为 Vorbis OGG 循环；发布只包括这些 OGG 的运行资源，原 WAV 作为可再生成源保留。未使用外部下载音频或他人音乐。生成脚本依赖 NumPy；PATH 中有 ffmpeg 时自动生成 OGG。

`scripts/audio_manager.gd` 缓存音频，20 路并发音效采用优先级分配，低优先级脚步不能打断高优先级命中。总音量、音效、音乐、环境分总线管理，Master 限幅；音源按玩家距离衰减。资源按固定逻辑路径加载，覆盖编辑器与导出 PCK 中不同的导入文件布局。近敌交战淡入战斗音乐，Boss 遭遇淡入 Boss 音乐，脱战/暂停退回探索配乐；环境床随房间交叉淡入。

动作、命中和碰撞在实际事件处触发，未用逐帧重复音效。落地声音覆盖攻击、受伤、格挡及翻滚等分支；下砸有独立重落地。升降台启停、压锤周期、机关操作和弹道撞墙接入物理声音。

## 玩家设置

Esc → 声音设置，四组音量滑杆、默认恢复和六种音效试听。设置自动保存到 `user://audio_settings.cfg`，不改角色进度。默认总音量 85%、音效 90%、音乐 55%、环境 65%。0.4.1 可直接继续 0.4 的正常存档。

## 验证

保留 65 项玩法/物理验收，新增 16 项音频验收，共 81 项。通过 Godot AudioEffectCapture 抓取本游戏 Master 混音 PCM，验证背景与动作非静音、攻击/命中/突进同时播放及峰值限幅；真实输入验证起跳、空冲、落地、翻滚。主线事件记录覆盖脚步、梯子、钩索、挥击、命中、弹反、弓弦、升降和齿轮，压锤周期与战斗/Boss/房间配乐状态另有运行检查。独立 EXE 再执行相同验收。

`qa/audio_assets.json` 记录采样、峰值、RMS、文件哈希；`qa/audio_runtime.json` 记录声卡驱动、输出设备、混音测量及事件计数；`qa/audio_mix_preview.wav` 是游戏内部混音截取，未录制麦克风或其他应用。没有人工听音或确认 Windows 应用音量/物理扬声器。最终通过与否以运行报告为准。
